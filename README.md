# 🚀 Track Workspace Chrome Extension

## 📌 About This Project

This project is a **productivity-focused Chrome extension** designed to help users manage:

* 📚 Reading materials
* ✅ Tasks with progress tracking
* ⏳ Deadlines across multiple tracks
* 📝 Notes per track

The goal is to provide a **clean, distraction-free workspace** where users can:

* Organize learning or project tracks
* Track time and progress
* Manage deadlines efficiently
* Quickly switch between different contexts

It is built with a focus on:

* ⚡ Fast interactions
* 🧠 Clear mental model (active vs finished items)
* 🎯 Minimal but powerful UI

---

## 🛠️ How to Install (Chrome Extension)

Follow these steps to run the extension locally:

### 1. Download / Clone the Project

```bash
git clone https://github.com/PragathiGyara/Chrome_productivity
```

---

### 2. Open Chrome Extensions Page

* Open Chrome
* Go to: `chrome://extensions/`

---

### 3. Enable Developer Mode

* Toggle **Developer Mode** (top right)

---

### 4. Load the Extension

* Click **Load unpacked**
* Select the project folder

---

### 5. Done 🎉

* The extension will now appear in your Chrome toolbar
* Click it to start using the workspace

---

## ⚠️ Notes

* Make sure all files (manifest, scripts, styles) are inside the selected folder
* If you make changes, click **Reload** in the extensions page
